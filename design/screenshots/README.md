# CoffeeSim design captures

These are static design reference captures for the three UI states. The
workspace does not include a headless browser executable, so they are annotated
SVG captures of the implemented layout rather than pixel screenshots from a
running browser session. Use them as the visual handoff baseline; replace with
browser captures when Playwright/Chromium is available.

- `init.svg` — scenario setup, Roasts, material coverage, and labor policy.
- `control-room.svg` — operating KPIs, plan controls, trace, anomalies, and events.
- `history.svg` — cumulative summary, strategy history, operating trace, and daily ledger.
